# SoundProject — Независимая музыкальная платформа

Многостраничный адаптивный веб-сайт для прослушивания и публикации независимой музыки.

## Структура проекта

- `index.html` — главная страница с интерактивной звуковой волной, трендами недели и быстрым поиском.
- `catalog.html` — каталог треков с живым поиском, фильтрацией по жанрам, сортировкой, избранным (`localStorage`) и быстрым просмотром.
- `product.html` — детальная карточка трека с характеристиками и запуском в плеере.
- `about.html` — информация о миссии и принципах платформы.
- `contacts.html` — контактные данные, социальные сети (ВКонтакте, MAX, Telegram, YouTube) и форма обратной связи с валидацией.
- `order.html` — форма подачи релиза в редакционную подборку.
- `css/custom.css` — кастомные стили в фирменной чёрно-оранжевой палитре с поддержкой переключения тёмной и светлой темы.
- `js/main.js` — сквозной аудиоплеер, управление темой (View Transitions API), фильтрация каталога, загрузка новых треков и валидация форм.
